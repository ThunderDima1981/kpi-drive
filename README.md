# KPI-Drive

Веб-приложение для мониторинга коэффициента результативности (КР) по матрице MBO Литягина. Считает только выполнение показателей. Оклады, зарплаты и денежные премии в модель не входят.

Данные команды хранятся в `localStorage` браузера. При первом открытии загружается демонстрационная команда: Иванов Иван и ещё четыре матрицы, чтобы на дашборде были красная, жёлтая и зелёная зоны.

## Запуск

```bash
npm install
npm run dev
```

Приложение откроется на [http://127.0.0.1:4317](http://127.0.0.1:4317).

Проверка расчёта:

```bash
npm test
```

Сборка:

```bash
npm run build
```

## Как устроен КР

Сумма весов матрицы должна быть равна 100%. Если это не так, на матрице появляется предупреждение, но вклад показателей всё равно считается.

КР = сумма по всем показателям (`% выполнения × вес / 100`).

- Количественный KPI: порог даёт 0%, план — 100%, от плана до максимума шкала растёт до потолка (по умолчанию 130%). Ниже порога выполнение обнуляется. Обратный показатель (расходы, ошибки) разворачивает шкалу: порог > план > максимум.
- Smart-задача: выполнение равно прогрессу руководителя от 0 до 100%.
- Стандарт: −2 = 0%, −1 = 70%, 0 = 100%, +1 = 115%, +2 = 130%.
